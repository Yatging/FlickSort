# 管理员使用说明

访问单独的 `/admin/`，使用已加入 `admin_users` 的 Supabase Auth 管理员登录。参与者从 `/experiment/` 进入，无需账户。请勿公开管理员密码，也不要在参与者设备登录后台。

首页显示全库人数、完成 Session、Trials 和 Events 数；默认仅筛选真实数据。可切换 Test / Demo / 全部，并按匿名 ID、起止日期、条件、Block 筛选。日期以数据库 UTC 日期为准。

刷新会重新读取所有分页；分布区显示 Classic/FlickSort × Low/High 的数量、准确率、平均有效耗时。只做基础描述，不能用来宣称统计显著性。

查看 Session 按钮显示相应原始数据。Trials 与 Events 导出遵循当前条件、Block和Session筛选；问卷遵循Session筛选。勾选“导出全部”将忽略所有筛选。CSV 对可能的公式起始字符进行转义。

后台标出未完成、完成数不符和超过5分钟未同步；重复 UUID 和重复试次由数据库约束拒绝。纯离线设备未到达服务端的失败需在参与者设备确认。

删除会永久删除当前 Session 和级联 Trials、Events、问卷、同步记录。应先确认撤回请求，并按团队政策处理已导出的 CSV 与备份。退出登录后内存访问令牌清除。页面刷新或令牌过期需重新登录。
